Prima di tutto: come aggiornare
Sceglie la via in base a dove usi le skill.
Da terminale — Claude Code
Nella casella dei messaggi di Claude Code:
/plugin marketplace update hevolus
/plugin update blueprints@hevolus
Poi riavvia la sessione: le skill si caricano all'apertura. La CLI si riscarica da sola al comando successivo. Solo la CLI, da una shell: xrcopilotlab-bp update
Da Claude Desktop
Scarica gli zip xrcopilotlab-….zip aggiornati dalla pagina delle release e ricaricali in Impostazioni → Capacità → Skill (sostituiscono i precedenti). Il plugin assessment si ricarica su claude.ai/customize/plugins.
Da Desktop si scrive, non si applica niente al tenant: per applicare serve la CLI, che c'è solo in Claude Code.
Sotto la 2.19.0 non arriva l'avviso automatico: fai i due comandi a mano. Una skill da sola su Claude Code: togli la cartella vecchia e scompatta lo zip nuovo al suo posto.
